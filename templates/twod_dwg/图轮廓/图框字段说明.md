# 容器二维图图框

模板为本目录的 `图轮廓.dwg`。生成时打开独立副本，按原 handle 填写；源模板不保存修改。
字段原文、handle 和坐标保存在 `图框字段映射.json`，生产映射在 `modules/TwoD/container_drawing_frame.py`。

全部文字沿用图轮廓模板的字体：原有文字仅修改内容，保留各自样式；新增标题栏/签名及视图文字使用 `lanpec`（`bpec_e.shx` + `hztxt.shx`），管口表表头使用 `TEXT`，数据使用 `技术要求`，尺寸文字使用 `DIM`（后三者为 `ysr.shx` + `hztxt.shx`）。保留模板字宽，不再创建宋体样式。重新生成图纸后生效。

## 字段与数据来源

| 内容 | handle | 数据来源 |
| --- | --- | --- |
| 设备名称（设备位号） | 8C2C2 | 产品需求库.产品需求表：产品名称、设备位号 |
| 型号 | 8C2C3 | 产品需求表：产品型号 |
| 项目名称、业主名称 | 8C2C4、8C2C5 | 由产品设计活动表.项目ID 查询项目需求库.项目需求表 |
| 设计版次、修订行版次 | 8C2C1、8C2BE | 产品需求表.设计版次；未填为 A |
| 日期、版本描述 | 8C2BF、8C2C0 | 生成日期、产品需求表.设计阶段 |
| 设计压力、设计温度 | 8C268、8C269 | 产品设计活动表_设计数据表的壳程数值；容器界面显示名为“数值” |
| 净重、充水后重量 | 8C26C、8C26D | 明确命名的整机数据；没有数据时填 /，不保留 1200/2400 示例 |
| 前端封头、容器圆筒、后端封头、接管材料 | 8C4A5～8C4A8 | 当前产品 ID 的元件计算结果表；锻件级别、覆层取当前元件或当前管口类别的附加参数 |
| 设计、校对、审核、会签、批准 | 原空白签名格新增文字 | 产品设计活动表中的对应字段 |

原“管程/壳程”设计数据列合为“容器”；原管箱、管板、换热管材料行替换为容器元件。
缺少字段显示 `/`。数据库读取错误会报错，不能把连接失败当作空数据继续生成。

## 管口表

按产品 ID 获取全部管口，不限定用途、功能或 N1～N6。一个物理管口一行，数量为 1；按代号自然排序，不合并相同功能的管口。

列为：代号、用途、公称尺寸、数量、压力等级、法兰型式、密封面、接管法兰材质、焊端规格、备注。
按用户确认，原“配对法兰”表头改为“接管法兰”，材质和焊端规格属于当前接管法兰。

- 公称尺寸、压力等级、法兰型式、密封面、用途、法兰标准来自管口表；尺寸、压力及输入焊端类型来自管口类型选择表。
- 法兰材质优先读取对应接管计算结果；缺失时用当前管口材料分类下的附加参数，按接管材料类型和牌号匹配第 1～3 组法兰材料牌号。类别参数覆盖通用参数，不读取其他类别。与换热器标注一致，钢锻件追加锻件级别；优先使用该管口的“接管法兰锻件级别”，旧数据未提供级别时沿用换热器的Ⅱ级口径。接管本体与法兰各取自己的级别。
- 计算结果优先按管口代号精确匹配，功能唯一时才使用“功能名 + 接管”。重复功能不能共享一个计算结果来填材质或焊端规格。
- 焊端规格优先采用计算结果中的“接管与管法兰或外部连接端壁厚（焊端规格）”，单位为 mm，与换热器取值口径一致。没有计算壁厚时才回退到管口表输入，并区分 Sch 和 mm。备注填写法兰标准。
- 原表实体重新生成，不复用六行示例内容。表格从标题栏上方向上增长，每页最多 50 行，超过时在同一 DWG 横向生成续页，并重复容器视图。
- 图框按现有视图边界缩放和定位，主视图、侧视图、底板详图及其尺寸实体不缩放。

## 视图尺寸的数据对应

生产出图按产品 ID 从 `产品设计活动表_元件计算结果表` 读取一次结果，主视图和图框共同使用。全局 `jisuan_output_new_tidai.json` 仅保留为离线数据组装入口，不用于生产出图。

长度按用户于 2026-09-14 确认的口径：先采用当前计算结果，不自行把设计输入的 T-T 长度换算成圆筒长度。当前核对产品的圆筒计算长度为 1200 mm，设计输入为 800（T-T）；此差异保留待后续确认长度基准。

管口计算结果与管口表使用同一套精确匹配规则；缺少唯一计算结果时报告具体管口，不用相似功能的另一管口代替。

法兰外径从 `材料库.管法兰外径表.D` 读取，按 DN/NPS、公称压力类型及数值、法兰型式匹配。法兰总高沿用换热器 `calc_nozzle_H` 的取值规则，从 `材料库.管法兰质量表` 按标准、尺寸、压力、法兰型式及密封面读取 `HRF/HFF/HRJ`。无法唯一匹配时报告管口，不使用估计值。计算结果中名为“接管法兰外径”的字段在当前产品中实际返回了法兰高度，不能直接作为视图外径。

## 验证

运行 `python -m unittest discover -s scripts -p test_container_drawing_frame.py`。
回归覆盖完整管口数据、重复功能、类别隔离、锻件级别、覆层、焊端计算值优先、DN/NPS 与压力等级匹配、外径和密封面高度、产品结果隔离、分页、图框范围、模板副本及失败清理。
本次还用模板转换出的 DXF 验证了 0、12、61 个管口，并转换生成测试 DWG；测试视图区为明确标注的占位几何，不是实际产品图。
2026-09-14 已按实际产品 `PD2026082509110201` 核对 10 个管口。DN100/DN80/DN50 的 WN Class150 RF 法兰外径分别为 230/190/150 mm，总高分别为 77/70/64 mm，焊端壁厚为 8/8/6 mm，接管法兰材质为 16MnⅡ。
本机 AutoCAD COM 仍不能连接到活动实例，以上属于数据库和代码验证，完整产品出图仍需在可用 AutoCAD 环境重新生成验证。

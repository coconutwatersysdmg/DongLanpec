# 防冲板恢复参数来源修复设计

## 目标

重新打开管束时，平板形、圆弧形和焊接式防冲板恢复所需参数以左侧“布管参数表”为权威来源，避免“布管输入表”缺少 `LB_Baffle*` 字段时防冲板不显示。

## 方案

- 在 `TubeLayoutEditor` 中集中解析防冲板恢复参数。
- 优先读取“布管参数表”中的防冲板厚度、折边角度、宽度、方位角、至圆筒内壁距离，以及换热管外径和中心距。
- 仅在参数表缺值时回退到历史 `input_json` 字段，兼容旧项目数据。
- 焊接式防冲板记录自身字段缺失时，回退到上述参数表值；不改变其逐条记录优先级。

## 非目标

不改变防冲板坐标保存格式、数据库表结构或三种防冲板的绘制算法。

## 备选方案

- 只补齐“布管输入表”：仍会保留两份参数来源，后续容易再次不同步。
- 恢复时直接查询数据库：会重复左侧参数表已经完成的加载工作，并增加连接与异常分支。
- 采用方案：从已加载的布管参数表读取，并用输入表兼容旧数据，改动最小且来源一致。

# 管板型式与 b_c 参数修复记录

## 型式限制

| 产品形式 | 默认管板型式 | 允许更改型式 |
| --- | --- | --- |
| AES、BES、AKU、BKU | a | 否 |
| AEU、BEU | a | 是 |
| NEN、NEN(H) | b | 否 |
| AEM、BEM | e | 否 |

页面初始化即应用限制，切换入口拒绝固定型式之外的选择，并保留当前节点和参数。操作开关打开时，固定型式内的节点仍可切换。

## 参数与数据库

旧代号 `e=30` 对应新代号 `α2=30`，旧代号 `h=3` 对应新代号 `e=3`。原转换逐键补全，误将已存在的旧 `e` 当成新 `e`。现在先识别整组代号，再从原始值转换；DL 快照取参使用相同转换。

已检查本地 MySQL 中包含“管板类型”列的表，并核对型式命名变体：当前使用的 b_c 数据仅存在于 `元件库.管板形式表`，产品设计活动库没有管板形式记录。`材料库.管板形式表` 还保留历史 `b_c型管板` 的 a～e 五个旧符号，其中旧 e=30 表示角度 α2，没有旧 h 对应的尺寸 e；这组历史角度值保持不变。

已事务更新元件库 b_c 的 7 条符号记录：a→α1、c→p1、d→d1、e→α2、f→R、g→n、h→e；b 保持不变。迁移后为 α1=60、b=2、p1=2、d1=1、α2=30、R=2、n=4、e=3。未修改其他节点、角度值或产品自定义参数。

原始 8 行完整记录保存在 `backups/tube-sheet-b-c-20261020-153301.json`，以“管板形式ID”可定位原记录。数据库提交后已通过实际参数读取函数再次确认 e=3、α2=30。

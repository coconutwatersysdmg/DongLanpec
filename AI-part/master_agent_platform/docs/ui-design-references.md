## 视觉与交互

- 浅灰蓝背景、白色内容面、蓝紫色操作强调。状态颜色继续表达运行、失败、待审等实际状态。
- 正文基准 12 pt（96 DPI 下约 16 逻辑像素）；支持 100%–160% 字号，偏好仅保存在平台工作区。
- 启动时开启 Qt 高 DPI 适配与高清图标。窗口初始大小受当前屏幕可用区域约束；字体不随窗口缩小而变小。
- 工具栏按可用宽度换行；侧栏可收起或拖动宽度，在低分辨率或大字号下可滚动。
- 模块卡片与运行卡片具有底部拖拽柄；内部表格、画布、日志通过分隔条调整。放大模式收起输入区，保留原对话归属。
- 模块编辑器共享主题，已打开的编辑器通过独立 appearance.json 同步字号，不占用业务指令通道。
- 表格列和行均可调整；几何阶段保留真实控制器和画布，空间不足时滚动查看。

## Agent 身份的边界

执行者来自实际任务的 `agent` 字段。`Orchestrator` 是本机主控编排服务，`Fabric` 是数据空间服务，`ReviewLoop` 是确定规则审核服务。
审核步骤只有在存在匹配的原文复查任务回执时才显示 `review_conditions`；规则校验不冒充大模型调用。

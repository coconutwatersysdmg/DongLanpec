## BEM 布管限定圆 DL 计算修正（管板型式图 d) / e_d 节点）

- 现象：DN800、do=25 的 BEM 产品，布管限定圆 DL 显示 784.0；需求文件图 d) 要求 774.22。
- 根因：`modules/buguan/buguan_ziyong/My_Piping.py` 中 `update_tube_layout_circle_dl` 的 e-d 分支
  用的是旧公式 `Dis - 2*((b/cosα1 + d1)*tanα2 + b) - 2e`（缺 2×R2 项），本例算得 785.6，
  再被兜底项 `Dis - 2*b3 = 784` 截断，界面因此显示 784.0。
- 修改：e-d 分支按需求文件改为 `DL = Di - 2×(2×R2 + d1×tanα2)`（α2 为角度），
  仅依赖 R2/d1/α2，不再要求 α1（空值不再触发回退）；保留 min(Dis-2b3, Dit-2b3) 兜底并打印三个候选值。
- 结果：800 - 2×(2×5 + 5×tan30°) = 774.2，与需求 774.22 一致。
- 测试：`tests/test_tube_layout_circle.py` 新增 `test_bem_d_plate_uses_requirement_formula_2r2_plus_d1_tana2`；
  e_d 通用用例期望由 1182.3 改为 1146.2；全套 78 项通过。
- 遗留：
  - 已保存的旧 DL 仍按“非首次打开保留库值”策略不自动覆盖，需重选管板图或改 Dis/do 触发重算。
  - 图 e)（e_e 节点）仍是旧的 cos/tan 公式，若需求文件图 e) 同为“2R2”型式需同步核对。
- 环境：venv 已损坏（缺 encodings），跑测试用 `D:/ProgramData/anaconda3/python.exe` + `QT_QPA_PLATFORM=offscreen`。

## 换热管外径 do 手动输入支持小数

- 现象：布管参数表「换热管外径 do」可编辑下拉框只能输整数（需求 2.2.1.10：数值类型 double，手输最大 57）。
- 根因：`My_Piping.py` 中该 combo 用的是 `QIntValidator(1, 99999)`，小数点被拦截。
- 修改：改为 `QDoubleValidator(0.0, 99999.0, 2)` + `StandardNotation` + `QLocale.c()`（固定 "." 小数点），
  上限仍不在输入阶段卡死，由 `validate_tube_do_input`（0 < do ≤ 57，弹窗+回滚）在提交链路校验。
- 验证：validator 对 25/25.4/19.05/57.15 均 Acceptable、abc 拒绝；QTest 模拟键入 “25.4” 成功。全套 78 项测试通过。
- 注意：中心距 S / 拉杆直径推荐表按标准 do（10~57）建键，非标小数 do 查不到映射时保持原值；`str(int(do))` 仅用于拉杆标准表回退。
